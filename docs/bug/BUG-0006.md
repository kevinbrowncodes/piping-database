# BUG-0006 — Global search matches numbers as substrings

> Status: Resolved · Severity: Medium (the headline feature returns the wrong row first) · Found: device QA 2026-09-03

## Summary

`SearchIndex.search` tests every query token with `haystack.contains`, so
numeric tokens match inside other numbers and standard names.

## Steps to Reproduce (search field on the Modules tab)

| Query | First results on device | Why |
|---|---|---|
| `sch 80 6` | 1/8" Sch 80, 1/8" Sch 80S, 1/4" … | "6" matches "b36.10" — every Sch 80 pipe hits |
| `2 300 wn` | 1/2", 1 1/2", 2", 2 1/2", 3 1/2", 12", 20", 42 A" | "2" matches inside every size containing a 2 |
| `weldolet 2` | 1/2", 1 1/2", 2", 2 1/2", 3 1/2", 12", 20", 24", 26" … | same |
| `2` (one char) | "No Results for “2”" | search runs only at ≥ 2 chars but the empty state still says No Results |

Also: olet subtitle renders "Run Order to run size" for rows without a
run range.

## Expected vs Actual

- **Expected:** numeric tokens match whole tokens (2 ≠ 12, 6 ≠ b36.10); the
  exact size/class row comes first; a 1-character query shows nothing (or a
  hint), not "No Results".
- **Actual:** as above.

## Root Cause

Substring matching over a flat lowercased haystack; no tokenisation; no
ranking; `ModuleListView` shows `ContentUnavailableView.search` whenever
`searchResults` is empty, including below the 2-character threshold.
Olet subtitle is `"Run \(o.runRangeText)"` and `runRangeText` already reads
"Order to run size".

## Acceptance Criteria

- [x] Haystack is tokenised; numeric query tokens (`2`, `300`, `1/2`, `80`)
      must equal a token; word tokens keep prefix/substring matching.
- [x] Results are ranked so entries whose size token equals a numeric query
      token sort first.
- [x] 1-character queries show no "No Results" panel.
- [x] Olet subtitle reads "Order to run size" / "Run 3/4" – 36"".
- [x] Unit tests for the four queries above.

---

## Resolution

`SearchIndex` now tokenises haystacks (mixed numbers such as "2 1/2" stay one
token), numeric query tokens must equal a token, word tokens still substring
match, and results whose own size equals a query number rank first (6" pipe
before the 1/8" pipe that is DN 6). Stainless schedules index their bare
number too ("80S" also answers "80"). `ModuleListView` only shows the search
list from two characters. Olet subtitles use `Olet.runSummary`. Tests:
`numbersMatchWholeTokensOnly`, `wordsStillMatchAnywhere`,
`oletSummaryReadsNaturally`; `SmokeTests.testSearchMatchesWholeNumbers`.

Verified: 60 unit + 5 UI tests green on the iPhone 17 Pro simulator (iOS 26.5), and re-checked on the iPhone 13 Pro (iOS 26.6.1) via WebDriverAgent on 2026-09-03 — the reproduction steps above now produce the expected result.
