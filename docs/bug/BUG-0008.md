# BUG-0008 — Provenance labels: Gaskets missing from Settings, flange Source string misleading

> Status: Resolved · Severity: Low (documentation in-app) · Found: device QA 2026-09-03

## Summary

1. Settings → Data sources lists six modules; **Gaskets (ASME B16.21)** is
   missing although the module shipped.
2. Flanges drilling card "Source" shows the file-level standard string
   "ASME B16.5 (Class 125 per ASME B16.1)" for every B16.5 class, which reads
   as if the Class 150 row came from B16.1.

## Steps to Reproduce

1. Settings tab → scroll to Data sources.
2. Modules → Flanges, Class 150, 2" → drilling card.

## Expected vs Actual

- **Expected:** Gaskets row present; Source reads "ASME B16.5" (or
  "ASME B16.1" for Class 125, "B16.47 Series A/B" for NPS ≥ 30).
- **Actual:** as above.

## Acceptance Criteria

- [x] Settings lists Gaskets · ASME B16.21.
- [x] Flanges Source label derived per row (series, else class 125 → B16.1,
      else B16.5); datasheet uses the same label; unit test.

---

## Resolution

Settings lists "Gaskets · ASME B16.21". `FlangesFile.FlangeSize.sourceLabel(class:)`
returns the B16.47 series for NPS ≥ 30, "ASME B16.1" for Class 125 and
"ASME B16.5" otherwise; the drilling card and the shared datasheet use it.
Test: `BugRegressionTests.flangeSourceLabelPerRow`.

Verified: unit suite green on the iPhone 17 Pro simulator (iOS 26.5); device re-check on the iPhone 13 Pro recorded below.
